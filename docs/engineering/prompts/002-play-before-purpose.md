# Prompt 002 -- Play Before Purpose

## Objective

Do **not** improve the existing hover effect.

Instead, answer a different question:

> Can a Passport experience invite me to play with it for 30 seconds
> before I even think about clicking it?

This is still a Motion Lab experiment.

Do not build Discovery. Do not build Atlas. Do not build additional
architecture.

---

# The Lesson From Sprint 001

The first prototype felt like a beautiful card with a hover effect.

It did **not** feel alive.

The problem is **not** polish.

The problem is **personality**.

Do not animate a card.

Perform the personality of Campfire.

---

# Campfire Personality

Archetype: - Gatherer

Purpose: - Bring people together.

Future Memory: - "The night nobody wanted to leave."

Personality:

- Warm
- Calm
- Welcoming
- Curious
- Comfortable
- Patient
- Alive
- Slightly unpredictable

If a motion does not reinforce one of these traits, remove it.

---

# Build Play

When the page loads, something should already be happening.

The world should feel like it existed before the user arrived.

The user should instinctively move their mouse around to see what
happens.

That curiosity is the success metric.

---

# Behaviours To Explore

These are experiments, not requirements.

## Continuous Life

The experience is never perfectly still.

Examples:

- subtle flame movement
- gentle breathing light
- tiny ember drift
- occasional larger spark
- slight warmth shimmer

## Curiosity

As the cursor approaches:

- the fire acknowledges the user
- not instantly
- not dramatically
- almost like someone looked up

## Drag

Allow the experience to be gently dragged.

It should not feel rigid.

Ideas:

- slight lag
- elastic return
- sparks trail briefly
- glow stretches slightly
- motion has weight

## Fire Behaviour

Fire should behave like fire.

Ideas:

- flicker
- breathe
- dance
- occasionally spit an ember
- vary naturally instead of repeating perfectly

## Surprise

Every so often something happens that is not directly triggered by the
user.

Keep it subtle.

The user should think:

"I wonder if that always happens."

---

# Constraints

Keep everything tasteful.

Do not become game-like.

Do not become noisy.

Avoid constant effects competing for attention.

Premium. Calm. Cinematic.

---

# Success Criteria

If a user opens Motion Lab and immediately begins:

- moving the cursor around
- dragging the experience
- waiting to see what happens
- experimenting out of curiosity

then this sprint succeeded.

If it still feels like a hover card, it failed.

Stop when the experience invites play.
