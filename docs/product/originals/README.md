# Passport's original product ideas

This folder keeps Passport's original product ideas, the ones that existed
before the doctrine and alongside it, in a form that survives conversation.
They used to live in chat, in Labs pages under `src/app/about/`, and in commit
messages.

**These files are not product authority.**
[`docs/PASSPORT-PRODUCT-DOCTRINE.md`](../../PASSPORT-PRODUCT-DOCTRINE.md) is.
Nothing here approves building anything. Moving an idea from here into the
doctrine is a separate decision for a person. Where something here appears to
conflict with the doctrine, the conflict is named in the file rather than
settled.

| File                                                         | What it holds                                                                                                                                    |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| [`go-have-a-day.md`](go-have-a-day.md)                       | GO HAVE A DAY / NOW GO HAVE ANOTHER and the ideas that make it up: Moments, Days, Another, conversation, the builder, Go Offline, paper, Boards. |
| [`fishing-with-emi.md`](fishing-with-emi.md)                 | The flagship acceptance experience: what the outing was, what it proves, and the bar any version of Passport has to clear.                       |
| [`idea-inventory.md`](idea-inventory.md)                     | Every original idea, with where it lives, how far it got, and its priority. The priority column has a gap, and the file says why.                |

from the ChatGPT Library into `docs/history/originals/`. See
[`docs/history/concepts.md`](../../history/concepts.md).

## Three kinds of statement

Every claim in these files carries one of three labels. They are not equal,
and they are not interchangeable.

- **Recovered.** An artifact in this repository already says it. The path, and
  where it helps the commit, is cited, and the quote is verbatim.
- **Stated.** Lorne said it in the mission brief of 2026-10-11 (Lodge,
  `lane/vision`), and no earlier artifact in this repository carries it. It is
  recorded because the brief named it, not because something here backs it up.
- **Proposed.** This document's own extension or reading. It has not been
  decided, nobody has asked for it to be built, and it must not be cited as
  intent. It sits here so it can be accepted, changed or thrown away on
  purpose.

If a claim carries no label, read it as **Proposed**.
